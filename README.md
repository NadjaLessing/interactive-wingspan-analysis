# Interactive wingspan analysis
Interactive jupyter notebook to visualise outcomes and stats of your Wingspan games.

Input a table with your scored points to
1) sort and select by player, category (total, eggs, tucked, ...) and points range.
2) create histograms showing total points and the contribution per category.
3) create pie-charts showing your wins, losses, ties.
4) show an averaged time series to see whether you improved.
